# FAQ - Часто задаваемые вопросы

## Авторизация

### Почему не работает авторизация?
Ошибка "Invalid credentials" возникает в 3 случаях:
1. **Неверный пароль** — используйте сброс пароля
2. **Блокировка аккаунта** — 5 неудачных попыток входа блокируют аккаунт на 30 минут
3. **Истёк срок действия подписки** — проверьте статус в личном кабинете

**Решение**:
- Проверьте раскладку клавиатуры (Caps Lock)
- Убедитесь, что email введён корректно
- Если аккаунт заблокирован — подождите 30 минут или обратитесь в поддержку

### Как сбросить пароль?
1. Откройте страницу входа
2. Нажмите "Забыли пароль?"
3. Введите email, привязанный к аккаунту
4. Проверьте почту (папка "Спам", если письма нет)
5. Перейдите по ссылке из письма
6. Введите новый пароль (минимум 8 символов)

**Время действия ссылки**: 24 часа

### Что делать, если аккаунт заблокирован?
После 5 неудачных попыток входа:
- **Автоматическая разблокировка**: через 30 минут
- **Срочная разблокировка**: обратитесь в поддержку через тикет

### Как включить двухфакторную аутентификацию (2FA)?
1. Личный кабинет → Безопасность
2. Нажмите "Включить 2FA"
3. Отсканируйте QR-код в приложении (Google Authenticator, Authy)
4. Введите код из приложения для подтверждения
5. Сохраните резервные коды в безопасном месте

## API

### Какие лимиты у API?
| Тариф      | Запросов/час | Запросов/день | Burst limit |
|------------|--------------|---------------|-------------|
| FREE       | 100          | 1000          | 10/сек      |
| PRO        | 1000         | 10000         | 50/сек      |
| ENTERPRISE | 10000        | 100000        | 200/сек     |

**Превышение лимита**: HTTP 429 Too Many Requests с заголовком `Retry-After`

### Как получить API ключ?
1. Войдите в личный кабинет
2. Перейдите в раздел "API" → "Ключи"
3. Нажмите "Создать ключ"
4. Дайте ключу имя (например, "Production")
5. Скопируйте ключ **немедленно** (он показывается один раз)

**Безопасность**:
- Никогда не коммитьте ключи в git
- Используйте переменные окружения
- Регулярно обновляйте ключи (каждые 90 дней)

### Какие форматы данных поддерживает API?
- **Request**: JSON (`Content-Type: application/json`)
- **Response**: JSON
- **Файлы**: multipart/form-data для загрузки

### Как обработать ошибку API?
```json
{
  "error": {
    "code": "INVALID_API_KEY",
    "message": "Предоставленный API ключ недействителен",
    "details": {
      "key_prefix": "sk_test_...",
      "created_at": "2026-01-15"
    }
  }
}
```

**Общие коды ошибок**:
- `400 Bad Request` — неверный формат запроса
- `401 Unauthorized` — проблема с API ключом
- `403 Forbidden` — недостаточно прав
- `404 Not Found` — ресурс не существует
- `429 Too Many Requests` — превышен лимит
- `500 Internal Server Error` — ошибка сервера

## Биллинг

### Как обновить подписку?
1. Личный кабинет → Биллинг → Тарифы
2. Выберите тариф (FREE / PRO / ENTERPRISE)
3. Нажмите "Обновить"
4. Введите данные карты
5. Подтвердите оплату

**Время активации**: мгновенно

### Какие способы оплаты доступны?
- Банковские карты (Visa, Mastercard, Мир)
- PayPal
- Банковский перевод (для ENTERPRISE)
- Криптовалюты (BTC, USDT)

### Как отменить подписку?
1. Личный кабинет → Биллинг → Подписка
2. Нажмите "Отменить подписку"
3. Выберите причину отмены
4. Подтвердите

**Доступ сохраняется** до конца оплаченного периода.

### Как получить счёт для юридического лица?
1. Личный кабинет → Биллинг → Счета
2. Нажмите "Выставить счёт"
3. Заполните реквизиты (ИНН, КПП, юридический адрес)
4. Скачайте счёт в PDF

**Срок оплаты**: 10 банковских дней

### Что происходит при неоплате?
- **День 1**: напоминание на email
- **День 3**: повторное напоминание
- **День 7**: приостановка доступа к PRO-функциям
- **День 30**: downgrade на FREE тариф

## Технические вопросы

### Где взять документацию MCP?
Документация доступна в разделе "Docs" → "MCP Integration"

**Содержание**:
- Установка и настройка MCP сервера
- Транспортные протоколы (stdio, HTTP, WebSocket)
- Регистрация инструментов (Tool annotation)
- Примеры использования (Python, TypeScript, Java)

### Как загрузить файлы в систему?
1. Откройте чат или тикет
2. Нажмите 📎 "Прикрепить файл"
3. Выберите файл (макс. 10MB для FREE, 100MB для PRO)
4. Дождитесь загрузки

**Поддерживаемые форматы**: PDF, DOCX, TXT, MD, PNG, JPG

### Почему возвращается ошибка 500?
Ошибка 500 (Internal Server Error) возникает при:
- Превышении размера файла (>10MB для FREE)
- Таймауте внешнего сервиса (MCP, AI API)
- Ошибке базы данных

**Решение**:
1. Проверьте логи сервера
2. Повторите запрос через 1 минуту
3. Если ошибка повторяется — создайте тикет с:
   - Временем ошибки
   - ID запроса (из заголовка `X-Request-ID`)
   - Шагами воспроизведения

### Как работает RAG поиск?
**RAG (Retrieval-Augmented Generation)**:
1. **Загрузка документов**: FAQ, документация, руководства
2. **Векторизация**: текст разбивается на чанки, создаются эмбеддинги
3. **Поиск**: по запросу находятся релевантные чанки (cosine similarity)
4. **Генерация**: LLM получает запрос + найденные источники → формирует ответ

**Параметры поиска**:
- `topK`: количество источников (по умолчанию 3)
- `threshold`: минимальная релевантность (0.0–1.0, по умолчанию 0.5)
- `augment`: добавлять источники в промпт (true/false)

### Какие модели AI поддерживаются?
- **qwen3.6-27b**: рекомендуется для tool calling
- **qwen3.5-397b-a17b**: может зацикливаться на tool calls
- **Другие OpenAI-совместимые**: через настройку `AI_API_URL`

**Настройка**: переменная окружения `AI_MODEL`

### Как подключить MCP сервер?
1. Backend → `/api/mcp/servers` (POST)
```json
{
  "name": "weather-server",
  "url": "http://host.docker.internal:8080/mcp",
  "transportType": "HTTP"
}
```
2. Подключите: `POST /api/mcp/servers/{id}/connect`
3. Проверьте инструменты: `GET /api/mcp/servers/{id}/tools`

**Транспортные типы**:
- `HTTP`: Streamable HTTP (рекомендуется)
- `STDIO`: стандартный ввод/вывод (для локальных процессов)
- `WebSocket`: realtime соединение

### Как отслеживать статус тикета?
1. Откройте `/support`
2. Выберите тикет из dropdown
3. Статус отображается в панели деталей

**Статусы**:
- `OPEN`: новый тикет, ожидает ответа
- `IN_PROGRESS`: в работе
- `PENDING`: ожидает информации от пользователя
- `CLOSED`: решён

**Уведомления**: email при изменении статуса

### Контакты поддержки
- **Email**: support@example.com
- **Чат**: /support (в приложении)
- **Время ответа**: 
  - FREE: 48 часов
  - PRO: 24 часа
  - ENTERPRISE: 4 часа
