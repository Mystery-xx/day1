# FAQ - Часто задаваемые вопросы

## Авторизация

### Почему не работает авторизация?
Ошибка "Invalid credentials" возникает в 3 случаях:
1. Неверный пароль — используйте сброс пароля
2. Блокировка аккаунта — 5 неудачных попыток входа
3. Истёк срок действия подписки

### Как сбросить пароль?
1. Откройте страницу входа
2. Нажмите "Забыли пароль?"
3. Введите email
4. Следуйте инструкциям из письма

## API

### Какие лимиты у API?
- FREE: 100 запросов/час
- PRO: 1000 запросов/час
- ENTERPRISE: 10000 запросов/час

### Как получить API ключ?
1. Войдите в личный кабинет
2. Перейдите в раздел "API"
3. Нажмите "Создать ключ"

## Биллинг

### Как обновить подписку?
1. Личный кабинет → Биллинг
2. Выберите тариф
3. Оплатите картой
